# CaUL — Phase 01 (giao diện mô phỏng)
Yêu cầu: Node 18+, Rust, và các phụ thuộc Tauri 2 (https://tauri.app/start/prerequisites/).
Linux: cần thêm libwebkit2gtk-4.1 và libayatana-appindicator3 (cho System Tray).

    npm install
    npx tauri icon app-icon.png   # tạo bộ icon từ ảnh 1024x1024 (đã kèm sẵn)
    npm run tauri dev
